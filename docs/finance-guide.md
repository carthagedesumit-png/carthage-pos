# CBOS Finance Guide

Finance uses immutable posted double-entry journals. Operational sales, returns, goods receipts, wallet/credit changes, inventory adjustments, and cash movements post through the idempotent integration layer.

Configure account mappings before pilot transactions. Use the opening-balance wizard once per store and effective date. Review Trial Balance, P&L, Balance Sheet, Cash Flow, General Ledger, Tax Center, and Integration reconciliation. Correct posted errors with reversing journals; never edit posted entries.
