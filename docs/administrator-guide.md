# CBOS Administrator Guide

Administrators manage users, stores, licensing, backups, diagnostics, maintenance, finance mappings, opening balances, and recovery. Start each pilot day at **Administration → Diagnostics**. Confirm database integrity, free disk space, license state, backup recency, API endpoint, and printer status.

Use **Maintenance Center** only during a quiet operating window. Every operation is recorded. Never remove ProgramData manually. Create and verify a backup before upgrades, bulk finance backfills, or configuration imports.

For unfinished checkouts, review the recovery suggestions and resume or void each cart. For accounting differences, use Finance Integration reconciliation; CBOS never silently changes ledger balances.
